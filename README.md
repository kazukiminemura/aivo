# aivo

**aivo** は、ChatGPT Voice Modeに近い自然な双方向音声会話を、ローカルPC上で実現するオープンソース志向のAI音声アシスタントです。

> **Status: 設計段階（v0.1）** — 本リポジトリには現時点でアプリ実装はありません。以下は開発予定の仕様であり、動作確認済みの機能を意味しません。

## 目標

- 日本語を中心に、マイクに向かって話すとローカルLLMが音声で応答する
- モデルを事前取得した後は、**クラウドAPIに依存せずオフライン**で利用できる
- 会話の文脈を維持し、将来的にストリーミング応答と発話割り込みに対応する
- Windows 11 / Ubuntu 24.04 のPCから始め、将来はスマートフォンUIにも展開する

## 技術方針（候補・未確定）

| 領域 | 第一候補 | 備考 |
| --- | --- | --- |
| UI | React + TypeScript + Vite | PCブラウザで利用 |
| 双方向音声 | セルフホストLiveKit + WebRTC | クラウドサービスは必須にしない |
| オーケストレーション | LiveKit Agents (Python) | 発話ターン・キャンセル制御 |
| 音声認識 | faster-whisper | CPU/GPU切替、代替としてsherpa-onnx |
| 発話検知 | Silero VAD | 初期は無音区間で終了判定 |
| 言語モデル | Ollama + 小型Qwen系モデル | 量子化4B級などを実測で選定 |
| 音声合成 | Kokoro / VOICEVOX | 日本語品質、ライセンス、遅延を検証 |
| API / 履歴 | FastAPI / SQLite | 保存はユーザー制御、初期段階はメモリ内で可 |

**注意**: 上記は採用候補です。各モデル・配布形態・音声ライセンス・商用利用条件および現行バージョンの互換性は実装前に再確認します。8GB VRAMでの同時動作と目標遅延は未検証です。

## MVPの完了条件

1. マイクからの日本語発話を認識し、ローカルLLMの回答を音声で再生できる
2. 直前の会話を踏まえて、10ターン連続の対話ができる
3. 初期セットアップ・モデルダウンロード後、インターネット接続なしで上記を再現できる
4. VAD / STT / LLM / TTSの処理時間を計測・記録できる

最初のMVPでは「自然な割り込み」「低遅延の逐次音声再生」は必須にしません。これらは次のフェーズで検証します。

## 開発の開始方法

まだ実装コード・依存パッケージ・起動手順は追加されていません。まず[開発計画](docs/development-plan.md)に従って、音声なしのLLM疎通から着手します。

## プライバシー方針

原則として音声・テキストを外部APIに送信しません。モデルの初回取得や依存パッケージ導入時にはインターネットを使用する可能性があります。履歴と録音の保存・削除は明示的な機能として設計します。
