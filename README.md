# aivo

ローカルPCで動く日本語の音声会話アシスタントです。マイク入力を認識し、Ollamaで返答を生成して、VOICEVOXまたは端末の日本語ローカル音声で読み上げます。任意のインターネット検索で天気予報やWeb検索結果を取得できます。

**状態：v0.1 MVP開発中。実装済み機能と実機での受け入れ合格は別です。** 自然な会話、応答速度、対応OSすべてでの安定動作はまだ保証していません。

開発に参加する方は、[開発者ガイド・現行アーキテクチャ](docs/architecture.md)から読み始めてください。コンテキスト図、プロセス構成、コンポーネント図、実在クラスの図、会話シーケンス、コードとテストへの導線をまとめています。[主要実装の選定理由](docs/architecture.md#9-主要実装の選定理由)では、記録された判断と実装からの推定、代替案・制約を分けて説明しています。

## できること

- 日本語の音声入力・返答・会話履歴の表示
- 接続中の会話の意図、目的、確定情報、未確認事項、直前の質問の保持
- 聞き取り・解析・返答を区別するアニメーション
- 読み上げ中の音声による割り込み、停止、新しい会話への切り替え
- 天気予報の取得、Web検索の抜粋表示、参照リンクの表示
- モデル・声・速度・認識デバイスの設定と、任意のローカル会話保存・削除

音声認識・LLM・音声合成はローカルで実行します。**外部検索は既定でON**です。検索時には抽出した検索語、地域名、予報用の座標・日付を外部サービスへ送信します。日本の行政区名がOpen-Meteoで見つからない場合は国土地理院にも地域名を送信します。検索語には会話から抽出された情報が含まれる場合があります。外部送信をしない運用は[オフライン利用](#オフライン利用)を参照してください。

## 使用モデルと構成

Issue #4・#9に記録された実機構成は **`qwen3.5:9b`（Q4_K_M）** です。以下の起動例も9Bに合わせています。ただし、コードと`.env.example`のフォールバック値は`qwen3:4b`のままです。`.env`がない場合やモデルを指定しない場合は4Bになるため、9Bを使うには明示的な設定が必要です。

| 機能 | 実装・設定 |
| --- | --- |
| UI・マイク取得 | ブラウザ標準API、AudioWorklet |
| API・音声転送 | FastAPI、WebSocket |
| 発話区間検出 | Silero VAD、無音待機800ms |
| 音声認識 | faster-whisper `small`。CUDA `int8_float16`を自動選択し、利用不可ならCPU `int8` |
| LLM | 実機検証構成：`qwen3.5:9b`。コードの既定値：`qwen3:4b` |
| コンテキスト | 4096トークン。履歴・意味状態・取得結果のための予算を考慮 |
| 出力上限 | `AIVO_MAX_TOKENS=192`。意味状態も生成する場合は384を追加、最大2048 |
| 音声合成 | VOICEVOX（speaker 3）または端末の日本語ローカル音声 |
| 天気・地名検索 | Open-Meteo、行政区名の補助検索に国土地理院 |
| 一般検索 | DuckDuckGo HTML検索 |
| 会話の保存 | 既定は接続中のみ。任意でローカルSQLiteへ本文を保存。モデル用履歴は最大20往復を上限に予算内で使用 |

モデル・量子化・実行デバイスは端末の設定によって変わります。`ollama list`、`ollama ps`、画面の「設定 → 応答時間・実行構成」で確認してください。4bitのLLMを使っても、音声認識や音声合成までINT4になるわけではありません。

## セットアップ

主な受け入れ対象はWindowsです。Ubuntu 24.04も対応要件に含まれますが、検証は別枠で未完了です。

Python 3.11〜3.13、[uv](https://docs.astral.sh/uv/)、[Ollama](https://ollama.com/)を用意してください。[VOICEVOX](https://voicevox.hiroshiba.jp/)は任意です。ブラウザはChromeまたはEdgeを使用します。初回の依存パッケージ・モデル取得にはインターネット接続が必要です。

リポジトリのルートで実行します。

```console
uv sync
uv run python -m aivo.setup
ollama list
```

音声認識モデルを`models/whisper-small`へ取得します。Ollamaに使用する9Bモデルがない場合は、Ollamaの起動後に取得します。

```console
ollama pull qwen3.5:9b
```

`uv run python -m aivo.setup --llm`でも設定済みのLLMを取得できます。

初めて設定ファイルを作る場合だけ、次を実行してください。既存の`.env`は上書きしないでください。

```powershell
# Windows PowerShell
Copy-Item .env.example .env
```

```bash
# Ubuntu
cp .env.example .env
```

必要な値だけ編集します。既存のモデル設定は自動変更しません。モデルを切り替える場合は取得済みのモデル名を指定してください。

```dotenv
AIVO_LLM_MODEL=qwen3.5:9b
AIVO_WEB_SEARCH=true
```

`.env.example`をコピーした後は、上記の`AIVO_LLM_MODEL=qwen3.5:9b`へ変更してください。9Bでの実機試験は限定的で、モデルの大型化だけで意味品質の問題が解消したとは判定していません。

## 起動と操作

1. Ollamaを起動します。必要なら別のターミナルで`ollama serve`を実行します。
2. VOICEVOXは任意です。使用する場合だけアプリまたはEngineを`http://127.0.0.1:50021`で起動します。未起動時は端末標準の日本語ローカル音声を使用します。
3. aivoを起動します。

```console
uv run uvicorn aivo.server:app --host 127.0.0.1 --port 8000 --ws-max-size 8192
```

[http://127.0.0.1:8000](http://127.0.0.1:8000)を開き、マイクを許可して「会話を開始」を押します。「設定」からマイク・接続状況・実行構成を確認できます。

- **停止**：マイクと再生を停止し、同じ接続の会話状態は保持します。
- **新しい会話**：履歴、意味状態、保留中の天気依頼を初期化します。
- **読み上げ中の発話**：旧音声を止め、新しい発話を受け付けます。準備・解析中は音声入力を受け付けません。

**コードや`.env`を変更した後は、aivoを停止して再起動し、ブラウザを再読み込みして新しい会話を始めてください。** 表示が古い場合はCtrl+F5で更新します。

既定の音声クレジットは **VOICEVOX:ずんだもん** です。公開・商用利用・配布前にVOICEVOXと各キャラクターの利用条件を確認してください。

## 天気とWeb検索

「東京都の今日の天気を教えて」「大阪市の明日の天気を教えて」「最新ニュースを検索して」のように話しかけます。

| 対象 | 動作と制限 |
| --- | --- |
| 天気 | 日別の予報、最高・最低気温、降水確率、最大風速を取得。今日から15日後まで、日本時間基準 |
| 日付 | 今日・明日・明後日と年付き明示日付をアプリ側で解決。地域確認後は保存した絶対日付を再利用 |
| 地域 | 発言から東京等の地域名を抽出。行政地名を保持し、別表記や国土地理院の地名検索で補完 |
| 一般検索 | 抜粋を原文で返し、数値・単位の言い換えを避ける。HTMLタグの除去・空白整形・長さ制限あり |
| 参照元 | 返答の下にリンクを表示。URL自体は読み上げない |
| 失敗・不足 | 地域・日付不足、曖昧な地域、対象期間外、取得失敗を扱う。取得できない情報は作らない |

[Open-Meteo](https://open-meteo.com/en/docs)と[地名検索API](https://open-meteo.com/en/docs/geocoding-api)の無料公開APIには非商用利用等の条件があります。[DuckDuckGo HTML検索](https://duckduckgo.com/duckduckgo-help-pages/features/non-javascript)はブロックやHTML変更で取得できない場合があります。

検索先の本文や公開日時は検証しません。抜粋が最新・正確であることや、花火等の開催可否を保証する機能ではありません。参照元と主催者の情報を確認してください。

## 会話状態と回答の扱い

通常のモデル回答は最終JSON全体を検証し、`reply`本文だけを表示・読み上げます。生成完了前の読み上げは行いません。天気や検索抜粋、取得失敗の返答は取得結果から直接作成し、モデルに再生成させません。

モデルが生成したfactsは、ユーザー発言の原文または以前に裏付けた引用と照合します。外部情報や推測をユーザーの事実として保存する問題を抑える仕組みです。ただし、返答全体の意味理解、主語・関係の抽出、意図・目的の正しさまで保証するものではありません。

録音は保存しません。会話本文は履歴保存を明示的に有効にした場合のみ永続保存します。処理時間やエラー種別はログへ出力します。停止やエラーを含む実際の動作は、実機での受け入れ確認が必要です。

## オフライン利用

依存パッケージと各モデルを事前取得したうえで、`.env`を次のように設定して再起動します。

```dotenv
AIVO_WEB_SEARCH=false
```

この設定ではアプリの外部検索処理を呼びません。OllamaとVOICEVOXの接続先はループバックHTTPに制限しています。オフラインでの実音声10ターンや復旧の受け入れ試験は未完了であり、端末全体の外部通信を遮断する設定ではありません。

## 問題の切り分け

- 認識文が違う：マイクとSTTを確認。スピーカー音声の混入が疑われる場合はヘッドホンで比較します。
- 天気が取れない：検索設定、地域・日付、外部通信を確認。`lookup_failed stage=... error=...`のログで分類処理と外部取得を区別します。
- モデルや設定が変わらない：サーバーを再起動し、新しい会話を開始。`ollama ps`と画面の実行構成を確認します。
- GPUメモリ不足：他アプリの使用量も確認。aivoは他アプリを自動停止しません。

## 保存と設定

「設定」で会話モデル、声、読み上げ速度（0.5〜2倍）、音声認識デバイス、外部検索、履歴保存を変更できます。「設定を保存」で`.env`へ保存します。モデルなどの反映にはaivo再起動が必要です。履歴保存のON/OFFは次の発話から反映し、既存の進行中の発話を後から保存対象にはしません。

履歴は既定OFFです。ONにした場合のみ完成した会話本文を`data/history.sqlite3`へ保存します。「保存した会話」から一覧・本文表示・個別削除・全削除ができます。停止や新しい会話は保存済みデータを削除しません。OFFにしても既存データは残るため、必要に応じて削除してください。保存済み会話はモデルへ自動再投入しません。DBと`.env`はGit対象外です。

## スピーカーの自己音声入力を防ぐ

音声による割り込みは、対応サーバーへの接続後に自動で有効になります。読み上げ中に話しかけると再生を止め、その発話を次の入力として処理します。割り込みボタンや有効化の操作は不要です。ブラウザのエコーキャンセルを使用しますが、端末標準の読み上げやスピーカー配置によっては自己音声が回り込むため、その場合はイヤホンを使用してください。

## VOICEVOXを起動せずに使う

音が出ない場合は、画面の「設定」から「音声テスト」を押してください。マイクや会話モデルを使わずに端末の読み上げを確認できます。開始できない場合はエラーを表示します。再生中と表示されても聞こえない場合は、サイトのミュート、Windowsの音量ミキサー、音声の出力先を確認してください。

既定の`AIVO_TTS_BACKEND=auto`では、VOICEVOXに接続できない場合、ブラウザのSpeechSynthesisで端末の日本語ローカル音声を使用します。常に端末音声を使う場合は`.env`に次を設定し、aivoを再起動してブラウザをCtrl+F5で更新してください。

```dotenv
AIVO_TTS_BACKEND=browser
```

画面に「読み上げ：端末標準（VOICEVOX不要）」と表示されます。日本語ローカル音声が見つからない場合は、Windowsの「設定 → 時刻と言語 → 言語と地域 → 日本語の言語オプション」で音声合成機能を追加し、ブラウザを再起動してください。OSの表示名は環境により異なります。ブラウザが`localService=true`として提供する日本語音声だけを選び、クラウド音声へは切り替えません。声質はVOICEVOXとは異なり、話者ID設定は適用されません。速度設定は使用できます。

`AIVO_TTS_BACKEND=voicevox`ならVOICEVOXのみを使います。端末標準音声でも文の順序・停止・割り込み・最終再生完了の通知を維持します。実際の音声パックの有無と実再生は端末での確認が必要です。端末での音声合成時間はサーバーのTTS計測に含めません。

## 音声認識モデルの変更（Windows）

Whisper baseからsmallへ切り替えるには、通常のPowerShellで実行します。

```powershell
.\upgrade-stt.ps1
```

モデルの取得とCPU int8での読み込み・無音推論が成功した場合だけ、`.env`の音声認識設定を更新します。失敗した場合は既存の設定を維持します。適用にはaivoの再起動が必要です。実際の認識精度はマイク音声で確認してください。

より大きいモデルを試す場合は、`.\upgrade-stt.ps1 -Model large-v3-turbo`も指定できます。CPUで実行するため、モデルの大型化に伴い会話の待ち時間が増える可能性があります。
