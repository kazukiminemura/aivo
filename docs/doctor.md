# 起動前提の診断（Issue #1）

Ollama・VOICEVOX・aivoを起動した状態で、リポジトリのルートから実行します。

```console
uv run python -m aivo.doctor
```

JSONでPython/OS、Git HEADと変更ファイル名、設定されたモデル、STT必須ファイル、Ollamaのモデル存在・量子化・ロード情報、VOICEVOXの話者、起動中aivoの実効設定との一致を確認します。サービス停止・接続拒否・設定不一致・モデル不足はfailedとなり、終了コードは1です。全前提を確認できた場合だけ終了コード0です。

このコマンドはファイルの保存・モデルの取得・ロード・音声入力を実行しません。STT不足時は復旧コマンドの候補を表示します。Whisperのサイズと出力先が意図した設定か確認してから手動実行してください。既存設定や他モデルを上書きする意図はありません。

passedは起動前提の確認のみです。実モデルの返答、GPUでの推論成功、実マイク・実再生、会話品質、オフライン性、性能の受け入れ合格ではありません。`actual_stt_device`がnullならサーバーでの推論デバイスは未観測です。モデルが/api/psにない場合も未ロードという情報であり、診断中にロードしません。

既定以外のローカルポートでaivoを起動した場合は`--app-url http://127.0.0.1:PORT`を指定します。外部ホストは指定できません。
