# ADR-001: ローカルMVPをFastAPIとWebSocketで構成する

- 日付: 2026-10-23
- 状態: 採用。最終回答プロトコルと会話品質を優先する既定値を追記。
- 対象: 単一PC・単一ユーザーの日本語音声会話。

## 背景

当初の[アーキテクチャ案](architecture.md)はReact、LiveKit / WebRTC、LiveKit Agentsを候補とし、構築負担が大きい場合はWebSocket代替案をADRとして記録する方針としていた。

まず発話認識→履歴付きローカルLLM→ローカルTTSを少ないプロセスで構築する。速度優先の0.6B / base設定では反復応答と認識品質の問題が報告されたため、既定を日本語会話の成立を優先する4B / smallへ戻す。実際の改善は別途確認する。

## 決定

UIはブラウザ標準APIとAudioWorklet、サーバーはFastAPIとする。同一オリジンのWebSocketで16kHz float32 PCMと制御イベントを交換する。React / Vite、LiveKit Server / Agentsは初版に導入しない。

Silero VADは同梱モデル、STTは事前取得済みfaster-whisper、LLMはローカルOllama、TTSはローカルVOICEVOXを使う。取得は明示的セットアップに限定し、既存モデルを再利用する。

現在の既定値と方針:

- Whisper small、beam size 3。CUDA `int8_float16`を自動選択し、利用不可ならCPU `int8`へ戻す。
- Qwen3 4Bを使用。この環境の既存モデルはQ4_K_Mで、量子化を検査する。Q4_K_Mは4bit中心の混合量子化であり、全処理・全テンソルINT4ではない。
- 最大出力192トークン、コンテキスト4096、無音待機800ms、常駐要求30分。
- 言いかけには確認し、訂正を受け付け、入力をそのまま繰り返さない対話方針を設定する。定型回答への置換フィルターは使わない。
- 完全な会話の組を保ち、保守的な文字数予算で古い組から履歴を削除する。直近20往復を常にすべて投入する保証はしない。
- `final-json-v1` として追加キーのないJSONオブジェクトを要求し、生成完了後に全体を厳密に検証する。検証済みの `reply` のみを文単位TTS・画面・履歴へ渡し、不正形式は読み上げずエラーにする。
- Qwen3はraw生成と明示的な会話プロンプトで旧テンプレートを回避する。UIはプロトコル・実行IDで旧サーバーを検出する。生成完了前の読み上げは行わない。

Listening / Speakingではマイク取得を継続し、ブラウザAECとサーバーVADで読み上げ中の割り込みを検出する。Processing / Preparing / Idleでは取得を止めるため、常時の同時対話方式ではない。割り込み時は旧ターンの通知・音声キュー・タスクを無効化し、直前音声を保持して次のターンへ渡す。中断した応答は履歴へ付記する。停止・新規会話は旧ターンと保留音声を破棄し、履歴は接続中のメモリだけに保持する。

## 効果と制約

- aivo自身はFastAPIの1プロセスで起動し、別途Ollama / VOICEVOXを起動する。UIビルドとクラウドアカウントは不要。
- 未検証の生成途中から読み上げる方式に比べ、初回音声までの待機が増える可能性がある。JSON構文が正しくても、`reply` の意味や自然さは保証しない。
- 小型化・量子化だけでは会話の成立も実行速度も保証しない。品質を確認した構成同士で遅延を比較する。
- GPU配置はVRAM空き容量とランタイム互換性に依存する。他プロセスを自動終了しない。
- WebRTCの帯域適応・ジッタ制御を持たず、ループバック利用を対象とする。
- STTスレッドの即時終了はできず、停止時は結果を破棄して同時推論を制限する。
- 5ターンのテキスト確認は狭い回帰チェックで、マイク・認識・合成・一般的な会話品質の検証を代替しない。
- 割り込みの既定値は発話確率0.65、連続160ms。物理エコーや雑音で誤検出する可能性があり、停止P95 ≤ 500msは未実測。
- 複数人利用、LAN公開、認証、TLSは対象外。

## 再検討する条件

割り込みの品質・エコー対策を改善する際や、遠隔端末・複数人利用の追加時にWebRTC / LiveKitを再評価する。判断には実機の初回再生遅延、停止時間、エコー誤検出、構築負担を使う。

当初文書のReact / LiveKitは将来案として残す。現在の構成と検証は本ADRと[実装・検証メモ](implementation.md)を参照する。
