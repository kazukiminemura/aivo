# ADR-002：外部取得と音声出力の受け入れ範囲

日付：2026-10-24。現行実装の判断を記録する。実機受け入れの合格記録ではない。

## 外部情報

ユーザーからインターネット検索・最新天気の利用を依頼された経緯に基づき、外部取得は既定ONを維持する。設定画面に外部送信の内容とON/OFFを表示し、READMEにも送信先・送信項目を記載する。音声・LLM・TTS推論はローカルで行う。
旧NFR-06の「外部送信なし」は、外部検索OFFでのアプリの動作として検証する。ON時の検索語・地域名・予報用の座標・日付の送信とは区別する。端末全体の通信遮断は保証しない。検索OFFの実機通信監視は未実施であり、合格扱いにしない。

## 最終回答検証

思考文や不正なJSONの漏出防止を優先し、モデル回答は全生成完了後に検証する。VOICEVOXの文単位合成・再生と読み上げ中の割り込みを継続する。元のFR-11 / AT-04の「LLM全生成完了前の再生」は現行MVPでは延期する。達成済みにはしない。再導入する際は、未検証出力を読み上げない方式と品質試験が必要。
性能目標は引き下げず、100ウォームターン以上の実再生計測と割り込み測定で比較する。現在の計測値と目標は別に記録する。

## 履歴・設定

履歴保存は既定OFF。明示的な有効化後に開始した発話の完成済みユーザー・assistant本文のみSQLiteへ保存する。録音・意味状態は保存しない。保存OFFは今後の保存を止め、既存データは残す。画面から個別・全削除できる。設定変更は履歴保存のみ即時、それ以外はaivo再起動後に適用する。
これらの実装・自動テストと、ブラウザからの実機操作・音声再生・60分安定性の合格は区別する。
