## 作業原則

1. **一段ずつ疎通**: LLM → VAD/STT → TTS → WebRTC → 連続対話の順に切り分ける。
2. **動作と目標の区別**: ベンチマーク目標を満たすと推測せず、使用条件を記録する。
3. **モデル交換性**: モデル呼び出しはAdapter越しに実装する。
4. **プライバシー**: 生音声の保存なし、外部推論APIなしを既定とする。
5. **Issues単位で進める**: 完了条件がテスト可能な小さな作業へ分割する。
