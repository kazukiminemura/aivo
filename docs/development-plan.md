# aivo 開発計画 v0.1

- 更新日: 2026-10-23
- 前提: [要件定義](requirements.md) と [当初のアーキテクチャ案](architecture.md)
- 現状: ローカル音声経路と会話品質の修正を実装。実モデル・実音声の受け入れは未完了。

現在の構成は[ADR-001](adr-001-local-mvp.md)に従うブラウザ標準API + FastAPI / WebSocketです。0.6B / baseで報告された反復応答・認識品質の問題を受け、既定をQwen3 4B Q4_K_M / Whisper small、無音800msへ戻しました。最終回答全体を検証した後の、文単位TTS・順次再生を維持しています。

チェック済みはコード・手順の追加済みを表し、Phase完了を意味しません。[README](../README.md)と[実装・検証メモ](implementation.md)に起動・検証手順を記載しています。

## 現在の検証結果

- 以前の修正時点ではPython17件・Node12件が通過。今回の最終回答プロトコル変更後の件数は、最新の実行結果で確認する。
- Python compileallとJavaScriptの構文確認が通過。
- 実Ollamaへ送る5ターン確認は、実行環境の `WinError 10013` により接続できず未完了。模擬サービスのテスト通過を、実モデルの品質改善や実音声の確認とは扱わない。
- このホストには指定モデルとSTTモデルがあり、再取得は不要。別環境の初回セットアップはREADMEに従う。
